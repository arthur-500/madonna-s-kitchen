# 🍲 Madonna's Kitchen

> Authentic Ghanaian Taste, Homemade with Love.

Madonna's Kitchen is a modern food business website showcasing our menu, story, and online ordering. Live in Accra, serving fresh local dishes daily.

**Live Site:**  https://arthur-500.github.io/madonna-s-kitchen/

---

### ✨ Features
- Beautiful responsive design (mobile + desktop)
- Our Menu with prices & categories
- About Us / Our Story
- Gallery
- Contact & Location with Google Maps
- WhatsApp Order Button
- Online ordering form

### 🍛 Our Specialties
- Jollof Rice & Chicken
- Waakye Special
- Fufu with Light Soup / Groundnut Soup
- Banku & Tilapia
- Fried Rice & More

### 🛠️ Built With
- React + Vite
- Tailwind CSS
- GitHub Pages
- GitHub Actions (Auto Deployment)
